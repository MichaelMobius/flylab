# Changelog v0.9 — MaleCNS Bridge

- Added **Cerebro: Proxy / MaleCNS Observe** selector.
- Added a Web Worker MaleCNS runtime.
- Added packed FLYN/FLYG decoders for `neurons.flyn` and `graph.flyg`.
- Added event-driven LIF network dynamics with transmitter-dependent signs.
- Added real ORN mapping from `bodymap.json` by glomerulus and antenna side.
- Added real identified sugar/taste neuron drive while feeding.
- Added approximate drive to real contact, haltere and Johnston's-organ populations from embodied state.
- Added real-spike aggregation into AL, MB, CX, SEZ, DN and VNC groups.
- Neural Inspector can now switch from proxy activity to MaleCNS spike-derived activity.
- Added MaleCNS network size, awake-neuron count, neural-speed and top-cell-type telemetry.
- CSV export switches to MaleCNS firing rates when the real bridge is active.
- Added remote public data loading and optional self-hosted `malecnsBase`.
- Retains all v0.8 compound vision and embodied behavior features.
